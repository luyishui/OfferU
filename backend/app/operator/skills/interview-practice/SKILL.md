# Interview Practice Skill

## Purpose
Practice interview questions using verified job and profile context.

## Required sequence
1. Activate the Skill and identify the target job or interview context.
2. Read only the context needed for the exercise.
3. Ask one question at a time, let the user answer, and give actionable feedback.
4. Keep drafts and coaching separate from durable profile or application writes.

## Safety boundaries
- Treat suggested answers as drafts, not official profile facts.
- Do not submit applications or modify records unless a separate confirmed capability is invoked.
