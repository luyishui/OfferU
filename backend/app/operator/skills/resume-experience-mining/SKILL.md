# Resume Experience Mining Skill

## Purpose
Interview the user to turn a bounded, user-confirmed experience into stronger resume bullets.

## Required sequence
1. Activate the Skill and identify the target ProfileSection when available.
2. Ask focused questions about the user's own contribution, scope, evidence, and exclusions.
3. Separate user-provided facts from wording suggestions and mark uncertainty.
4. Present a draft for user review before any profile patch.
5. Apply a confirmed, proposal-gated patch only to the registered target fields.

## Safety boundaries
- Never upgrade participation into ownership or invent metrics.
- Preserve role boundaries and explicit exclusions.
- Do not write to unrelated profile sections or resume output without a separate contract.
